Xurupizzas



O Xurupizzas é um sistema de gerenciamento de pizzaria desenvolvido em Java, utilizando a IDE Apache NetBeans. O projeto busca facilitar a organização das atividades de uma pizzaria por meio de uma interface gráfica e de uma estrutura organizada em diferentes pacotes, separando as classes de controle, modelos e interfaces.



Como executar



Para executar o projeto, faça o clone do repositório utilizando o comando:



git clone https://github.com/HenriGuedes68/Xurupizzas.java.git





Após baixar os arquivos, abra o Apache NetBeans, selecione a opção File → Open Project, localize a pasta do projeto e abra-a. Em seguida, execute a aplicação pela IDE.



Tecnologias utilizadas



Java, Apache NetBeans, Git e GitHub.
